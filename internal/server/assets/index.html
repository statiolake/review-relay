Keyboard

    

      
j k
Move the current line (count: 5j)

      
gg G ^d ^u
Top / bottom / half page

      
{ }
Previous / next file

      
[ ]
Previous / next change

      
^p ^n
Previous / next thread, across files (follows the panel filter)

      
V
Select lines

      
a
Add a thread on the current line or selection

      
r e x dd
On the current line's thread: reply / edit a comment / delete a comment / delete the whole thread. Several candidates get numbers to choose from

      
s
Resolve the current line's thread (done; hidden from Waiting / Answered), or reopen a resolved one

      
zo zc zR zm
Show / hide the thread on the current line (a resolved thread expands first); show / hide all. On folded lines, zo or Enter unfolds

      
Space
Toggle reviewed for the file

      
/ 
Find in file; Enter accepts, then n / p step

      
Go to file

      
 Esc
Submit / cancel

    

    
Click a line number to comment. Drag or Shift-click to select a range.
